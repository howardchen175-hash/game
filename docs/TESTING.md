# 验收与测试

## 自动验证

- `npm run check`：Prettier、严格 TypeScript、5 项核心/数据库测试、权威 XLSX 快照一致性、Vite 构建。
- `npm run test:e2e`：2 项集成/浏览器流程测试，由真实 PostgreSQL 与 Chromium 执行。
- 世界测试使用 20 个固定 seed 覆盖连通性、唯一 ID、最小间距、长环路、坐标边界、天体数量、初始铁铀/七槽、矿藏守恒、迷雾字段和数据源舰船基准。
- 数据库测试建立临时独立 schema，验证空库/旧认证版本升级、重复迁移、唯一约束及级联删除。结束清理自己的 schema。
- 接口测试使用两个随机账户：并发四次创建只成功三次、同幂等键重试不新增存档、不支持版本返回 409、拒绝越权读取/删除、拒绝错误 Origin、拒绝错误名称删除、软删除后复用槽位、相同世界返回、退出及旧 Cookie 重放失效、重新登录可恢复、显示名更新、修改密码撤销其他会话且旧密码无法登录。
- 浏览器测试走注册 → 创建存档 → 银河搜索 → 未知星系 → 未知行星隐藏信息 → 母星 → 设施/舰船 → 刷新恢复 → 窄屏 → 对话框 Escape → 确认删除 → 退出。检查没有页面脚本错误和 390px 横向溢出。
- 测试账户使用 `@test.invalid` 与每次新生成密码，测试后只删除当次创建的用户。不提供固定密码、不重置 owner play。

浏览器可执行路径默认 `/usr/bin/chromium`，可用 CHROMIUM_PATH 覆盖。截图和失败 trace 写入忽略目录 `.local` / `test-results`。截图不作为账户凭证发布。

## 个人试玩步骤

1. 按 README 启动并注册自己的邮箱与密码。先看到「我的宇宙」，此时没有星图。
2. 创建一个有名称的存档，进入九大星域银河图；搜索 `R2-S01`，进入未知星系并选择行星，确认矿藏/槽位不会泄露。
3. 点击「返回母星」，确认新曙光为 Medium / 120 / 7 槽，铁矿与铀矿始终存在；可查看其他起始矿种。
4. 查看「我的殖民地」和「舰船档案」；本版设施不可运行，舰船不可派遣。回到星图，试用缩放、拖动、标签和星域高亮。
5. 刷新、退出并重新登录，重新进入存档，确认宇宙不变。返回存档页，新建其他存档，最多三个。
6. 用另一个账户确认看不到之前的存档。在测试存档执行删除：名称错误不删除，准确名称确认后不可进入。
7. 账户设置中改名和修改密码。修改密码撤销其他设备会话；本版未实现邮箱找回，请妥善保留自己的密码。

用户的真实试玩尚待进行。自动浏览器流程不能替代用户对节奏与交互的反馈。本版没有时间推进玩法，不要求两小时生产或 72 小时跨设备运行验收。
